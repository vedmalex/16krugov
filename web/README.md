# Web

Веб-клиент на Preact и Vite. Запуск из этой папки: `npm ci`, затем `npm run dev`. Сборка: `npm run build`.

GitHub Actions собирает `web/dist` при отправке в `master` и передаёт его в GitHub Pages. В настройках Pages источником должен быть выбран GitHub Actions. Ожидаемый адрес без пользовательского домена: https://vedmalex.github.io/16krugov/.
