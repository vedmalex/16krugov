# Артикуляционный тренажёр — пакет разработки

Приложение: https://vedmalex.github.io/articulation-trainer/

Сайт автоматически собирается и публикуется через GitHub Actions при изменениях в ветке `main`. Локальный запуск: `npm ci`, затем `npm run dev`.

Полное ТЗ, архитектура, стартовая библиотека упражнений и **11 авторских скороговорок** из текущей беседы.

## Состав
- `docs/PRD.md` — продуктовые требования и пользовательские сценарии.
- `docs/SPEC.md` — функциональная спецификация, UX, таймер, метроном, прогресс, тесты и критерии приёмки.
- `docs/ARCHITECTURE.md` — архитектура и модели данных.
- `docs/CONTENT.md` — редакционная спецификация и текстовые упражнения для чтения.
- `data/vowels.json` — разминка гласных.
- `data/consonants.json` — 10 групп согласных с тремя уровнями.
- `data/tongue_twisters.json` — 11 скороговорок с полными текстами.
- `data/programs.json` — программы тренировки.
- `examples/exercise.schema.json` — базовая JSON Schema для упражнений.

## Приоритет реализации
1. Приложение без регистрации: гласные, согласные, последовательное чтение, таймер, метроном, локальный прогресс.
2. Генератор комбинаций, скороговорки, пользовательские программы, режим памяти.
3. Запись речи, измерение темпа, исследовательская оценка ошибок.

Все JSON-файлы — UTF-8. Скороговорки созданы в беседе и не являются цитатами из священных писаний.
