# PRD — Помощник для джапы и артикуляции (16 кругов)

**Версия:** 2.0 · **Язык:** русский · **Платформы:** Web (прототип/PWA) → iOS / Android · **Статус:** продуктовая спецификация.

---

## 1. Цель и концепция продукта

Создать удобный цифровой инструмент, помогающий практикующему повторять джапа-медитацию внимательно, чисто и с глубоким духовным погружением.

Продукт объединяет две неразрывные части садханы:
1. **Подготовка артикуляции:** физическая готовность речевого аппарата к длительному произнесению звуков мантры без усталости, зажимов и «проглатывания» слогов.
2. **Ассистент повторения мантры:** поддержка осознанности и сосредоточения ума во время чтения кругов с помощью наставлений ачарьев, покруговых настроек из книг и счётчика кругов.

---

## 2. Проблемы пользователей и ценность

| Проблема практикующего | Решение в приложении |
|---|---|
| Усталость губ, языка и челюсти при чтении нескольких кругов | 3–5 минутная артикуляционная разминка (гласные, согласные, скороговорки). |
| Механическое («сухое») повторение мантры, блуждание ума | Предварительный настрой и тематические тексты/шлоки на каждый круг. |
| Сбивается счёт кругов на чётках при отвлечении | Крупная и надёжная кнопка фиксации круга с индикацией прогресса. |
| Желание прочитать больше шлок или задержаться на любимом тексте | **Полная развязка:** перелистывание текстов/шлок независимо от смены круга. |
| Разрозненные источники и бумажные книги | Все настройки из книг («Лучшие круги», «Бхакти-расаяна») структурированы в одном месте. |

## 3. Аудитория

- Практикующие вайшнавы, ежедневно повторяющие фиксированное число кругов мантры Харе Кришна (4, 8, 16, 24, 32, 64 круга).
- Начинающие преданные, осваивающие правильное произношение и структуру джапа-медитации.
- Чтецы и ведущие киртанов, готовящие речевой аппарат к качественному звучанию.

*Примечание:* приложение является инструментом личной духовной практики и тренировки дикции; не позиционируется как медицинская диагностика или логопедическая терапия.

## 4. Ключевые сценарии использования (User Journey)

### Сценарий А. Подготовка артикуляции (перед джапой)
1. Пользователь открывает приложение и выбирает раздел «Подготовка артикуляции».
2. Проходит быструю разминку (гласная лестница, маятники), отрабатывает сложные сочетания согласных или выбирает авторские скороговорки на темы лил Кришны.
3. Речевой аппарат разогрет, звуки святого имени произносятся отчётливо и легко.

### Сценарий Б. Сессия джапа-медитации
1. **Выбор цели:** пользователь выбирает количество кругов на сессию: **4, 8, 16, 24, 32, 40, 48, 56 или 64 круга**.
2. **Настройка на чтение:** открывается экран преднастройки с наставлением о внимательном слушании, пяти условиях правильной джапы и молитвенном настроении (по материалам книги «Лучшие круги»).
3. **Чтение кругов (покруговой режим):**
   - На экране отображается номер текущего круга (например, «Круг 1 из 16») и шкала прогресса.
   - Для текущего круга загружается соответствующая настройка: практический совет для ума + шлока на санскрите с переводом.
   - Пользователь повторяет круг на чётках, удерживая в уме предложенную медитацию.
4. **Независимое перелистывание текстов:**
   - Если пользователь хочет прочитать предыдущую или следующую шлоку из коллекции (например, из «Бхакти-расаяны»), он перелистывает карточку стрелками («← Предыдущий текст» / «Следующий текст →»).
   - **Номер текущего круга при этом НЕ меняется.**
5. **Фиксация завершения круга:**
   - Завершив чтение круга на чётках, пользователь нажимает крупную контрастную кнопку **«Следующий круг»**.
   - Счётчик увеличивается (круг 2 из 16), обновляется индикатор прогресса, карточка может автоматически предложить настройку для следующего круга.
6. **Завершение практики:**
   - После завершения целевого круга кнопка меняется на «Завершить чтение».
   - Открывается завершающий экран с молитвой об устранении оскорблений (из книги «Лучшие круги», глава 99) и статистикой сессии.

## 5. Требования к продукту

### Функциональные требования
- **Выбор цели:** фиксированные пресеты: 4, 8, 16, 24, 32, 40, 48, 56, 64 круга.
- **Двухуровневая навигация в джапе:**
  - Управление прогрессом чтения (круг N из Target, кнопка «Следующий круг»).
  - Управление текстом/шлокой (листание вперед/назад, возврат к настройке текущего круга).
- **Библиотека первоисточников:**
  - Книга «Лучшие круги» (Варшана дас): 16 глав с пошаговой настройкой на каждый круг, вводные правила, молитвы.
  - Книга «Шри Бхакти-расаяна» (Шачинандана Свами / Санатана Госвами): коллекция шлок для углубленной медитации.
- **Артикуляционный тренажёр:**
  - 5 видов гласной разминки, 10 групп согласных с тремя ступенями сложности, 11 тематических скороговорок.
  - Метроном, регулировка темпа (BPM), автоускорение, подсветка слогов, аудио-сигналы.
- **Автономность и локальное хранение:**
  - Работа без сервера и без обязательной регистрации.
  - Сохранение истории сессий и настроек в браузере (LocalStorage / IndexedDB).

### Нефункциональные требования
- **Mobile-first дизайн:** оптимизация для управления одной рукой на смартфоне (большие кнопки, удобное переключение во время удержания чёток).
- **Экран без засыпания (Screen Wake Lock):** подсветка экрана не гаснет в процессе чтения круга.
- **Тёмная и светлая темы:** комфортное чтение ранним утром в полумраке (брахма-мухурта).
- **Быстродействие:** мгновенный отклик на нажатия, плавная анимация переходов, отсутствие зависаний таймеров.

## 6. Организация структуры проекта

В соответствии с требованиями исходные файлы структурированы по назначению:
- `content/books/` — папка с первоисточниками:
  - `content/books/luchshie-krugi/` — книга «Лучшие круги» с разбивкой по главам и 16 кругам.
  - `content/books/bhakti-rasayana/` — книга «Шри Бхакти-расаяна» и база данных шлок.
- `web/` — выделенная папка веб-версии (React/Preact + Vite), готовая к сборке и публикации на GitHub Pages.
- `docs/` — единый центр спецификаций и архитектурных документов.

## 7. Этапы реализации (Release Phases)

### Этап 1: Прототип веб-приложения (Завершён)
- Организация структуры папок проекта (`content/books/`, `web/`, `docs/`).
- Базовый веб-интерфейс на Preact/Vite с интеграцией артикуляционного тренажёра.
- Выбор целевых кругов (4, 8, 16, 24, 32, 40, 48, 56, 64).
- Экран джапы с кнопкой «Следующий круг» и демонстрационным перелистыванием текстов.

### Этап 2: Полнофункциональная Web-версия (PWA)
- Импорт всех 16 глав книги «Лучшие круги» в структурированный JSON-каталог настроек.
- Интеграция базы шлок «Шри Бхакти-расаяна» с поиском и выбором шлок для круга.
- Реализация Screen Wake Lock API (экран не тухнет во время джапы).
- Таймер сессии и круга (время круга, среднее время, общее время).
- Звуковой/тактильный сигнал при переключении круга (колокольчик/вибрация).
- Молитва об устранении оскорблений на экране завершения.
- Офлайн-работа через Service Worker (PWA).

### Этап 3: Мобильные приложения для iOS и Android
- Сборка нативных/кроссплатформенных приложений (React Native / Expo).
- Тактильная отдача (haptic feedback) при нажатии кнопки следующего круга.
- Фоновый режим таймера и интеграция с системными виджетами (Lock Screen / Live Activities).
- Локальные напоминания о времени джапы и садханы.

## 8. Границы MVP (Что НЕ входит в начальную версию)
- Серверная синхронизация и единый аккаунт в облаке.
- Платные подписки и реклама.
- Социальные сети и публичные рейтинги чтения джапы.
- Автоматическое распознавание речи мантры через микрофон (счётчик переключается пользователем вручную).
