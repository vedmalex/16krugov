### 2.2. Улучшение UX экрана джапы
- [ ] **Таймер сессии и круга:**
  - Отображение текущего времени на данном круге (с автосбросом при переходе).

  - Расчёт среднего времени на круг.
- [ ] **Screen Wake Lock API:**
  - Автоматическое предотвращение отключения дисплея смартфона во время активного чтения мантры.

  - Сводка сессии: сколько кругов прочитано, общее время, средний темп.
  - Сохранение факта сессии в историю (LocalStorage / IndexedDB).

## Фаза 3: Мобильные приложения для iOS и Android 📱 *(План)*

- [ ] **Выбор технологического стека:**
  - Рекомендуется: **React Native + Expo** для максимального переиспользования TypeScript-кода и стейт-машины сессии.
- [ ] **Нативные адаптеры:**
  - `expo-keep-awake` для надёжного удержания подсветки экрана.
  - `expo-haptics` для приятной тактильной отдачи при нажатии на чётках.
  - `expo-av` для воспроизведения звуков завершения круга в фоновом режиме.
- [ ] **Специализированный мобильный UX:**
  - Управление физическими клавишами громкости (опция переключения круга нажатием качельки громкости в чехле/кармане).
  - Поддержка Dynamic Island и Live Activities на iOS (отображение текущего круга и таймера на заблокированном экране).
  - Виджеты для домашнего экрана (цель на день, текущий прогресс).
- [ ] Публикация в App Store и Google Play.
