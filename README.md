# Помощник для джапы

Прототип объединяет подготовку артикуляции и помощник для повторения мантры.

- `web/` — веб-приложение. Запуск: `cd web && npm ci && npm run dev`.
- `content/books/luchshie-krugi/` — книга «Лучшие круги».
- `content/books/bhakti-rasayana/` — книга «Бхакти-расаяна» и шлоки.
- `docs/` — документация и планы проекта.

Тексты настроек в прототипе пока демонстрационные.
