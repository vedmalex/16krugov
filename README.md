# Помощник для джапы (16 кругов)

Интерактивный ассистент для внимательной и осознанной джапа-медитации. Проект объединяет два взаимодополняющих этапа:
1. **Подготовка артикуляции** — разминка речевого аппарата, чистота и лёгкость произнесения звуков мантры.
2. **Ассистент повторения мантры (джапа)** — погружение ума, покруговая настройка на основе книг и священных текстов, подсчёт кругов с независимым изучением шлок.

---

## Концепция проекта

Чтение джапы требует собранности ума и физической готовности речевого аппарата:
- **Разминка артикуляции:** тренировка гласных и согласных звуков, снятие зажимов челюсти и языка, отработка чёткости произношения святого имени через авторские упражнения и скороговорки.
- **Настройка и погружение ума:** перед началом и на каждом круге практикующему предлагается духовный настрой — наставление ачарьев и шлоки из священных писаний, помогающие удерживать внимание на звуке мантры.
- **Счётчик кругов и выбор цели:** возможность задать цель на сессию (4, 8, 16, 24, 32, 40, 48, 56 или 64 круга).
- **Развязанное перелистывание:** переключение круга (кнопка «Следующий круг») и перелистывание шлок/настроек независимы — можно углубляться в чтение текстов, не сбивая счётчик кругов, и наоборот.
- **Крупная кнопка «Следующий круг»:** эргономичный элемент управления, удобный для нажатия во время медитации без необходимости отвлекаться от чёток.

## Книги и контентные источники

1. **«Лучшие круги» (Варшана дас):**
   - Практическое руководство по внимательной джапе на основе трудов вайшнавских ачарьев.
   - Часть 1: Пять условий лучших кругов, способы концентрации ума.
   - Часть 2: Настройка перед чтением, 16 пошаговых медитаций на каждый из 16 кругов, молитва об устранении оскорблений.
   - Расположение: [content/books/luchshie-krugi/](file:///Users/vedmalex/work/16krugov/content/books/luchshie-krugi/).

2. **«Шри Бхакти-расаяна» (Шачинандана Свами / Санатана Госвами):**
   - «Эликсир преданности» — глубокие наставления и шлоки для погружения ума в расу и настроение служения.
   - База данных шлок: [Sri Bhakti Rasayana Slokas.jsonl](file:///Users/vedmalex/work/16krugov/content/books/bhakti-rasayana/Sri%20Bhakti%20Rasayana%20Slokas.jsonl) и [Sri Bhakti Rasayana Slokas.md](file:///Users/vedmalex/work/16krugov/content/books/bhakti-rasayana/Sri%20Bhakti%20Rasayana%20Slokas.md).

3. **Молитвенные и богослужебные тексты (из библиотеки ачарьев `acaryas-lib`):**
   - **Шри Кевалаштакам** ([content/prayers/bhajana/](file:///Users/vedmalex/work/16krugov/content/prayers/bhajana/)): восьмистишие Шрилы Нилакантхи Госвами о славе святого имени в трех редакциях (полная, связная интерлинеарная, пословная).
   - **Утренняя служба ISKCON** ([content/prayers/morning-service/](file:///Users/vedmalex/work/16krugov/content/prayers/morning-service/)): Гурваштака, Вибхавари-шеша, Нрисимха-пранама, Туласи-пуджа, Шикшаштака, 10 оскорблений святого имени.
   - **Молитвы месяца Карттика** ([content/prayers/krtik-month/](file:///Users/vedmalex/work/16krugov/content/prayers/krtik-month/)): Дамодараштакам, Гаура-арати, Шад-Госвами-аштакам, Радха-крипа-катакша-стотрам.

## Платформы и запуск

### Веб-версия (`web/`)
- Стек: Preact, TypeScript, Vite, Web Audio API, IndexedDB.
- Локальный запуск:
  ```bash
  cd web
  npm ci
  npm run dev
  ```
- Сборка:
  ```bash
  npm run build
  ```
- Публикация: автоматический деплой на GitHub Pages через GitHub Actions при пуше в `master` ([https://vedmalex.github.io/16krugov/](https://vedmalex.github.io/16krugov/)).

### Мобильные приложения (в планах)
- Реализация для iOS и Android на базе общего TypeScript-ядра (модели данных, машина состояний сессии джапы, каталог текстов).
- Планируется использование React Native / Expo для единой кодовой базы с поддержкой тактильного отклика (вибрация при переключении круга), фонового режима и виджетов.
